# VoiceBoard

## 跨境电商用户反馈与产品路线图平台

独立开发｜Streamlit + Pandas + SQLite + DeepSeek｜2026-10-23

> 把分散的用户声音变成可解释、可追溯、可执行的产品路线图。

# 一、为什么做这个项目

跨境电商平台每天产生大量来自不同国家、用户类型和商品品类的反馈。传统评论分析往往停留在词云或情绪比例，无法回答产品经理最关键的三个问题：什么问题最重要，为什么重要，下一版本具体做什么。

VoiceBoard 将分析和执行连接起来。它从真实 CSV 开始，经过分类、影响评估和优先级计算，最终形成负责人、状态与目标版本明确的需求卡。

# 二、项目不是固定数据演示

- 首次启动为空数据库，不自动加载样例数据。
- 页面指标、Top 5 排名和原始证据全部来自用户实际上传的反馈。
- 每次导入先预览，用户确认后才在一个事务中写入 SQLite。
- 相同反馈通过 SHA-256 指纹去重，重复上传不会制造虚假增量。
- 刷新浏览器或重启应用后，反馈、修订和路线图仍然存在。

# 三、完整产品闭环

## 1. 收集反馈

用户下载空白 CSV 模板，上传包含反馈正文、国家、用户类型、商品品类、评分和日期的数据。系统检查 10 MB 文件上限、20,000 行上限、UTF-8 编码、必填字段、评分、日期和影响程度。

## 2. 归类问题

系统支持两种真实分类方式：

- 离线规则：覆盖物流、支付、商品质量、搜索推荐、客服和退换货，输出命中关键词与置信度。
- DeepSeek：调用官方 HTTPS JSON API，返回分类、影响程度、置信度和理由。

无法可靠判断的反馈进入“待确认”，不会被强行分入某类。产品经理可以人工修正，系统记录修改前后值和原因。

## 3. 判断影响与排定优先级

用户可以按国家、用户类型和商品品类组合筛选。每个问题的优先级为：

```text
优先级得分 = 当前筛选范围内出现频次 × 平均影响程度
```

看板同时展示反馈总量、高影响反馈、待确认数量、覆盖市场、优先级矩阵、排名和原始证据。排序使用未舍入值，保证计算稳定。

## 4. 制定迭代计划

Top 5 痛点附带可编辑的产品方案和原始反馈证据。点击“转为需求卡”后，系统保存当时的指标和筛选快照，并进入产品路线图。

需求卡支持负责人、待评估/已规划/开发中/已上线、目标版本、方案编辑、归档和恢复。这样形成从用户声音到迭代执行的完整闭环。

# 四、技术架构

```text
Streamlit 五个工作页面
        ↓
Import / Feedback / Insight / Roadmap Services
        ↓
Importer + Rule/DeepSeek Classifiers + Pandas Analytics
        ↓
Parameterized Repository
        ↓
SQLite: batches / feedback / revisions / roadmap
```

模块各自承担一个职责：页面不直接拼 SQL，分类器不负责持久化，分析函数不修改数据，仓储层不包含页面逻辑。这使每一层都能独立测试和替换。

# 五、安全与可靠性

- DeepSeek 密钥只从会话输入或环境变量读取，不写入代码、数据库或日志。
- API 只允许 DeepSeek 官方 HTTPS 主机，禁止重定向并设置连接和读取超时。
- 模型输出被视为不可信数据，必须通过分类枚举、数值范围和 JSON 结构校验。
- 所有 SQL 值使用参数绑定，动态列只允许白名单。
- 导出 CSV 会中和电子表格公式前缀，避免打开文件时执行恶意公式。
- 导入使用事务；API 或数据库失败不会留下半批数据。

# 六、测试策略

自动化测试覆盖 CSV 边界、SQLite 事务、六类规则、DeepSeek 失败路径、组合筛选、人工修订、优先级、Top 5、需求卡、导出安全和 Streamlit 空状态。

真实浏览器端到端验收已完成：从空库启动，上传 11 条测试反馈并确认写入，人工修订 1 条分类，查看优先级排名，生成 1 张需求卡，将状态更新为“开发中”，再重启服务验证 SQLite 持久化。浏览器控制台错误为 0，截图和复现说明见 `docs/e2e-verification.md`。

# 八、项目价值

对 Shopee 产品经理岗位而言，VoiceBoard 展示的不只是编码能力，而是一条可解释的产品决策方法：

- 从用户反馈中建立一致的问题分类。
- 使用明确指标而不是主观印象排定需求。
- 保留证据、筛选范围和优先级快照，使决策可复盘。
- 把洞察直接转成负责人、版本和状态明确的迭代计划。
- 同时考虑异常处理、数据安全、测试和可维护性。
