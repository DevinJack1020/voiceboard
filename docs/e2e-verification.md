# 浏览器端到端验收记录

验收日期：2026-10-23

环境：Windows、Python 3.14、Streamlit 1.66、Microsoft Edge（无头模式）

## 验收范围

测试从全新的空 SQLite 数据库开始，使用 `tests/fixtures/e2e_feedback.csv` 中的 11 条跨境电商反馈执行完整主路径：

1. 验证首页为空库状态，不展示虚构指标。
2. 上传 CSV，完成字段校验与六类离线规则分类预览。
3. 用户确认后，将 11 条反馈真实写入 SQLite。
4. 在反馈明细页人工修订 1 条分类，并写入修订审计记录。
5. 查看基于“频次 × 平均影响”的优先级看板和原始证据。
6. 将 Top 1 痛点转为需求卡，保存负责人和目标版本。
7. 在产品路线图中将状态更新为“开发中”。
8. 关闭并重启 Streamlit，再次读取同一数据库验证持久化。

## 验收结果

| 检查项 | 结果 |
| --- | --- |
| 浏览器主流程 | 通过 |
| 写入反馈 | 11 条 |
| 人工修订审计 | 1 条 |
| 路线图需求卡 | 1 张 |
| 最终需求状态 | 开发中 |
| 重启后持久化 | 通过 |
| 浏览器控制台错误 | 0 |

DeepSeek 外部调用使用自动化模拟响应覆盖成功和异常路径，避免验收过程产生真实费用；真实接口代码通过官方 HTTPS 地址、超时、禁止重定向和响应结构校验实现。浏览器主流程使用无需联网的离线规则完成。

## 可复现命令

`scripts/e2e_browser.py` 会创建主流程数据；`scripts/e2e_persistence.py` 应在服务重启后使用同一数据库执行。两者要求本机安装 Microsoft Edge，并设置 `VOICEBOARD_DB_PATH`。
